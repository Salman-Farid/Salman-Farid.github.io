# salmanfrahman.engineer

Source for my personal portfolio site, published at **[www.salmanfrahman.engineer](https://www.salmanfrahman.engineer)**.

Built with **Flutter Web** and deployed automatically to GitHub Pages on every push to `main`.

## Live demo

**[www.salmanfrahman.engineer](https://www.salmanfrahman.engineer)**

## Stack

- **Flutter Web** — single-page portfolio
- **GitHub Pages** — hosting, custom domain via `CNAME`
- **GitHub Actions** — build and deploy on push

## Repository contents

This repository holds the **built output** (`index.html`, `main.dart.js`, `canvaskit/`, `assets/`) that GitHub Pages serves. It is generated by `flutter build web` — edit the Flutter project source, not these files.

| Path | Purpose |
|---|---|
| `index.html` | Entry point |
| `main.dart.js` | Compiled application |
| `canvaskit/` | CanvasKit rendering engine |
| `CNAME` | Custom domain mapping |

## Local development

```bash
# from the Flutter portfolio project source
flutter build web --release
# copy build/web/* into this repository, then commit
```

To preview the built output locally:

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Custom domain

The site is served from `www.salmanfrahman.engineer` (see `CNAME`). The apex domain redirects to `www`.
